# 个人任务工作台

适用于 macOS 13 及以上版本，包含 Apple 芯片和 Intel 两种架构。看板、甘特图和归档可离线使用，数据保存在当前 Mac 用户账户下。

## 安装与使用

按[从源码构建](#从源码构建)生成安装包后，解压 `dist/个人任务工作台.zip`，将「个人任务工作台」拖到「应用程序」并双击打开。首次打开是带有默认分组的空看板。点击「新建任务」或按 ⌘N 创建第一项任务。

## 迁移和备份

1. 在原来记录任务的浏览器和工作台地址中刷新页面，点击右上角「导出备份」，保存 JSON 文件。
2. 打开 Mac 客户端，选择「文件 → 导入工作台备份…」并选取该文件。
3. 核对任务、分组和归档的数量，点击「导入并替换」。此操作会替换客户端当前的工作台，包括看板和甘特图各自的排序。

日后可用「文件 → 导出工作台备份…」备份客户端数据，或迁移到另一台 Mac。

## 从源码构建

在装有 Xcode 命令行工具和 macOS SDK 的 Mac 上，从项目根目录运行：

```sh
./macOS/build.sh
```

脚本将 `web/workspace.html` 嵌入 AppKit 和 WebKit 客户端，生成 `dist/个人任务工作台.app` 和 ZIP 压缩包，并校验解压后的签名及架构。当前构建使用本机临时签名。
